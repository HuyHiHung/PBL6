Tiếng Anh cho sinh viên IT: từ vựng nền tảng, giới thiệu project, giao tiếp nhóm và báo cáo/xử lý lỗi.

**Mức mục tiêu:** A2–B1 · **Thời lượng:** 280 phút.

**Quy mô:** 4 chủ đề, 12 bài, 102 mục từ/cụm từ theo bài và 100 câu hỏi.

**Mục tiêu:** Sử dụng từ vựng IT trong câu; giới thiệu project và luồng demo; báo tiến độ, hỏi trợ giúp và viết báo cáo lỗi rõ ràng.

> Bản dành cho người duyệt có đáp án. Chưa nhập CMS, không kèm audio. Hội thoại dùng để đọc phân vai; tình huống và số liệu là giả lập.

Biên soạn mới cho Sprout. Mức A2–B1 là mục tiêu ngôn ngữ, chưa được thẩm định độc lập; thuật ngữ có giải thích tiếng Việt. Các project và hội thoại là tình huống giả lập, không mô tả trạng thái triển khai thực tế của Sprout.

## Chủ đề 1: IT Vocabulary Foundations

Đọc mô tả công việc IT ngắn; phân biệt các thuật ngữ thường gặp; luyện nhớ từ bằng flashcard hai chiều.

### Bài 1.1: Computers and Files

**Mục tiêu:** Gọi tên thiết bị, phần mềm và thao tác với tệp; phân biệt hardware với software, upload với download.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| hardware | noun, uncountable | phần cứng; các bộ phận vật lý của máy tính | computer hardware |
| software | noun, uncountable | phần mềm; chương trình chạy trên máy tính | install software |
| device | noun | thiết bị | a mobile device |
| keyboard | noun | bàn phím | use a keyboard |
| file | noun | tệp; một đơn vị dữ liệu được lưu với tên | save a file |
| folder | noun | thư mục; nơi tổ chức tệp hoặc thư mục con | create a folder |
| install | verb | cài đặt | install an app |
| update | verb | cập nhật | update the software |
| upload | verb | tải lên; gửi dữ liệu từ thiết bị đang dùng tới hệ thống khác | upload a file |
| download | verb | tải xuống; nhận dữ liệu từ hệ thống khác về thiết bị đang dùng | download a file |

#### Ví dụ Anh–Việt

- **hardware:** The team checks the computer hardware. — Nhóm kiểm tra phần cứng máy tính.
- **software:** We install new software on the laptop. — Chúng tôi cài phần mềm mới trên máy tính xách tay.
- **device:** You can open the app on a mobile device. — Bạn có thể mở ứng dụng trên thiết bị di động.
- **keyboard:** I use a keyboard to type my name. — Tôi dùng bàn phím để gõ tên.
- **file:** Save the file before you close the app. — Lưu tệp trước khi đóng ứng dụng.
- **folder:** Create a folder for the lesson files. — Tạo một thư mục cho các tệp bài học.
- **install:** Please install the app on your computer. — Hãy cài ứng dụng trên máy tính của bạn.
- **update:** We update the software after class. — Chúng tôi cập nhật phần mềm sau giờ học.
- **upload:** Upload your homework from your laptop to the website. — Tải bài tập từ máy tính xách tay của bạn lên website.
- **download:** Download the lesson from the website to your laptop. — Tải bài học từ website về máy tính xách tay của bạn.

#### Cách dùng và mẫu câu

Dùng động từ nguyên mẫu để hướng dẫn: Save the file. Thêm please để lịch sự: Please install the app. Hardware và software thường không đếm được: dùng some software hoặc a piece of software, không dùng a software trong nghĩa phần mềm nói chung.

#### Đọc trong ngữ cảnh

Mai uses a laptop for her project. She creates a folder called Lessons. She downloads a lesson file from the class website to her laptop. She saves the file in the folder. Then she uploads her homework from the laptop to the website.

**Yêu cầu:** Xác định Mai tải tệp từ đâu về đâu trong hai thao tác download và upload.

#### Thực hành

Che cột nghĩa và tự nhớ 10 từ; sau đó nhìn nghĩa để nói từ tiếng Anh. Viết hai câu với upload và download, nêu rõ nơi gửi và nơi nhận. Mẫu: I upload a file from my laptop to the website. I download a file from the website to my laptop.

#### Quiz — 5 câu

1. Which word means the physical parts of a computer?

   - A. Folder
   - B. Hardware
   - C. Software

   **Đáp án: B.** Hardware là phần cứng; software là phần mềm.

2. Choose upload or download: I ___ a lesson from the website to my laptop.

   **Đáp án: download.** Nhận tệp từ website về máy của mình là download.

3. Where does Mai save the lesson file? (Dựa vào bài đọc.)

   - A. On a keyboard
   - B. In the Lessons folder
   - C. In a new app

   **Đáp án: B.** Mai tạo thư mục Lessons rồi lưu tệp vào thư mục đó.

4. Choose install or upload: Please ___ this app on your computer.

   **Đáp án: install.** Install an app nghĩa là cài một ứng dụng.

5. Which action sends homework from your laptop to a website?

   - A. Download the homework
   - B. Upload the homework
   - C. Create a keyboard

   **Đáp án: B.** Gửi tệp từ máy đang dùng lên website là upload.

### Bài 1.2: Building and Testing Software

**Mục tiêu:** Hiểu từ chỉ người, mã nguồn, chức năng, lỗi và các thao tác kiểm tra phần mềm.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| developer | noun | người phát triển phần mềm; lập trình viên | a software developer |
| code | noun, uncountable | mã; các chỉ dẫn được viết bằng ngôn ngữ lập trình | write code |
| function | noun | hàm; một đơn vị mã thực hiện tác vụ | call a function |
| variable | noun | biến; tên dùng để tham chiếu một giá trị trong chương trình | declare a variable |
| feature | noun | tính năng của sản phẩm | add a feature |
| bug | noun | lỗi trong phần mềm | fix a bug |
| debug | verb | gỡ lỗi; tìm và xử lý nguyên nhân lỗi | debug the code |
| test | verb | kiểm thử | test a feature |
| repository | noun | kho lưu mã nguồn và lịch sử thay đổi trong ngữ cảnh quản lý phiên bản | a code repository |
| commit | verb | ghi lại thay đổi thành một phiên bản trong kho quản lý phiên bản | commit changes |

#### Ví dụ Anh–Việt

- **developer:** The developer builds a learning app. — Lập trình viên xây dựng một ứng dụng học tập.
- **code:** We write code for the quiz page. — Chúng tôi viết mã cho trang câu hỏi.
- **function:** This function checks the answer. — Hàm này kiểm tra câu trả lời.
- **variable:** This variable stores the score. — Biến này lưu điểm số.
- **feature:** We add a flashcard feature to the app. — Chúng tôi thêm tính năng thẻ từ vựng vào ứng dụng.
- **bug:** There is a bug on the quiz page. — Có một lỗi trên trang câu hỏi.
- **debug:** We debug the code to find the problem. — Chúng tôi gỡ lỗi mã để tìm vấn đề.
- **test:** Please test the new feature. — Hãy kiểm thử tính năng mới.
- **repository:** The team keeps the project code in a repository. — Nhóm lưu mã nguồn project trong một kho mã.
- **commit:** I commit my changes with a short message. — Tôi ghi lại các thay đổi bằng một commit có thông điệp ngắn.

#### Cách dùng và mẫu câu

Dùng a/an với danh từ đếm được số ít: a bug, a feature, a variable. Phân biệt function (hàm trong mã) và feature (tính năng người dùng sử dụng). Commit ghi lại thay đổi trong kho; thao tác này không đồng nghĩa với tải mã lên máy chủ.

#### Đọc trong ngữ cảnh

Nam is a developer. He adds a flashcard feature to a learning app. One function checks the answer. A variable stores the score. Nam finds a bug: the score is always zero. He debugs the code and fixes the bug. Then he tests the feature and commits his changes.

**Yêu cầu:** Tìm tính năng Nam xây dựng, lỗi gặp phải và việc Nam làm sau khi sửa lỗi.

#### Thực hành

Giới thiệu phần việc trong project bằng 3 câu. Mẫu: I add a quiz feature. I fix a bug. I test the feature. Tạo flashcard riêng cho cặp function / feature và bug / debug.

#### Quiz — 5 câu

1. What is a feature?

   - A. A problem in the code
   - B. A named value
   - C. Something the product lets users do

   **Đáp án: C.** Feature là tính năng sản phẩm, ví dụ học bằng flashcard.

2. Choose bug or developer: A ___ builds software.

   **Đáp án: developer.** Developer chỉ người phát triển phần mềm.

3. What problem does Nam find? (Dựa vào bài đọc.)

   - A. The score is always zero
   - B. The folder is empty
   - C. The keyboard is broken

   **Đáp án: A.** Bài đọc nêu the score is always zero.

4. Choose variable or repository: A ___ stores the score in Nam's program. (Dựa vào bài đọc.)

   **Đáp án: variable.** Trong đoạn văn, biến lưu giá trị điểm số; repository lưu mã nguồn và lịch sử.

5. Which phrase means finding and fixing problems in code?

   - A. Create a folder
   - B. Download a lesson
   - C. Debug the code

   **Đáp án: C.** Debug the code là gỡ lỗi trong mã.

### Bài 1.3: Web Apps and Data

**Mục tiêu:** Hiểu vai trò của trình duyệt, giao diện, máy chủ và dữ liệu; dùng các cụm send a request và receive a response.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| browser | noun | trình duyệt web | open a browser |
| frontend | noun | phần giao diện và tương tác phía người dùng của ứng dụng | build the frontend |
| backend | noun | phần xử lý phía máy chủ của ứng dụng | build the backend |
| server | noun | máy chủ hoặc chương trình cung cấp dịch vụ cho bên yêu cầu | send data to a server |
| database | noun | cơ sở dữ liệu; tập hợp dữ liệu được tổ chức để lưu và truy xuất | store data in a database |
| request | noun | yêu cầu gửi tới hệ thống hoặc dịch vụ | send a request |
| response | noun | phản hồi cho một yêu cầu | receive a response |
| account | noun | tài khoản | create an account |
| log in | phrasal verb | đăng nhập | log in to an account |
| deploy | verb | triển khai ứng dụng vào một môi trường để chạy và sử dụng | deploy an app |

#### Ví dụ Anh–Việt

- **browser:** Open the learning website in your browser. — Mở website học tập bằng trình duyệt của bạn.
- **frontend:** The frontend shows the quiz questions. — Phần giao diện hiển thị các câu hỏi.
- **backend:** The backend checks the user's answer. — Phần xử lý phía máy chủ kiểm tra câu trả lời của người dùng.
- **server:** The app sends the answer to the server. — Ứng dụng gửi câu trả lời đến máy chủ.
- **database:** The app stores lesson titles in a database. — Ứng dụng lưu tên bài học trong cơ sở dữ liệu.
- **request:** The browser sends a request for the lesson. — Trình duyệt gửi yêu cầu lấy bài học.
- **response:** The browser receives a response from the server. — Trình duyệt nhận phản hồi từ máy chủ.
- **account:** Create an account to save your progress. — Tạo tài khoản để lưu tiến độ học của bạn.
- **log in:** I log in to my account before class. — Tôi đăng nhập vào tài khoản trước giờ học.
- **deploy:** We deploy the app to a test server. — Chúng tôi triển khai ứng dụng lên một máy chủ thử nghiệm.

#### Cách dùng và mẫu câu

Log in là động từ hai từ: I log in. Login thường là danh từ hoặc từ bổ nghĩa: the login page. Dùng send a request và receive a response. Các ví dụ frontend/backend mô tả một ứng dụng web đơn giản, không quy định kiến trúc cho mọi hệ thống.

#### Đọc trong ngữ cảnh

Linh opens the learning app in a browser. She logs in to her account. She selects a lesson. The browser sends a request to the server. The backend reads the lesson from a database and sends a response. The frontend shows the lesson. The team deploys a new version to a test server before the demo.

**Yêu cầu:** Tìm từ chỉ nơi lưu bài học, yêu cầu gửi đi và phản hồi nhận về.

#### Thực hành

Nói luồng mở bài học bằng 3 câu: The browser sends a request. The server sends a response. The frontend shows the lesson. Che câu mẫu và nói lại; hoạt động này không chấm tự động.

#### Quiz — 5 câu

1. Which word means a program used to open websites?

   - A. Browser
   - B. Database
   - C. Variable

   **Đáp án: A.** Browser là trình duyệt dùng để mở website.

2. Choose request or response: The browser sends a ___ to ask for a lesson.

   **Đáp án: request.** Request là yêu cầu gửi đi; response là phản hồi.

3. Where does the backend read the lesson from? (Dựa vào bài đọc.)

   - A. A variable called score
   - B. A database
   - C. A keyboard

   **Đáp án: B.** Đoạn văn ghi reads the lesson from a database.

4. Complete with the two-word verb meaning đăng nhập: I ___ to my account.

   **Đáp án: log in.** Động từ đăng nhập là log in, viết thành hai từ.

5. Which phrase means making an app available in a running environment?

   - A. Type a word
   - B. Name a folder
   - C. Deploy the app

   **Đáp án: C.** Deploy là triển khai ứng dụng vào môi trường để chạy và sử dụng.

## Chủ đề 2: Describing Your Project

Giới thiệu vấn đề, người dùng, tính năng và phạm vi của project bằng câu ngắn; trình bày một luồng demo.

### Bài 2.1: Who Is Your App For?

**Mục tiêu:** Nêu mục tiêu, đối tượng sử dụng và nhu cầu mà project giải quyết.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| project | noun | dự án | a student project |
| goal | noun | mục tiêu | the main goal |
| user | noun | người dùng | a new user |
| learner | noun | người học | an English learner |
| problem | noun | vấn đề cần giải quyết | solve a problem |
| need | noun | nhu cầu | a user need |
| purpose | noun | mục đích | the purpose of the app |
| target audience | noun | nhóm người dùng hướng đến | identify the target audience |

#### Ví dụ Anh–Việt

- **project:** Our project helps students learn English. — Dự án của chúng tôi giúp sinh viên học tiếng Anh.
- **goal:** Our main goal is to make revision easier. — Mục tiêu chính của chúng tôi là giúp việc ôn tập dễ hơn.
- **user:** A new user can choose a lesson. — Người dùng mới có thể chọn một bài học.
- **learner:** The app is for English learners. — Ứng dụng dành cho người học tiếng Anh.
- **problem:** We want to solve this problem. — Chúng tôi muốn giải quyết vấn đề này.
- **need:** Quick revision is an important user need. — Ôn tập nhanh là một nhu cầu quan trọng của người dùng.
- **purpose:** The purpose of the app is to support daily practice. — Mục đích của ứng dụng là hỗ trợ luyện tập hằng ngày.
- **target audience:** Our target audience is first-year students. — Nhóm người dùng chúng tôi hướng đến là sinh viên năm nhất.

#### Cách dùng và mẫu câu

Our app is for + nhóm người dùng. It helps + người + động từ nguyên mẫu: It helps students review words. Its purpose is to + động từ: Its purpose is to support practice. Phân biệt vấn đề hiện tại và mục tiêu mong muốn.

#### Đọc trong ngữ cảnh

## Chủ đề 4: Bugs and Troubleshooting

Viết báo cáo lỗi có bước tái hiện và kết quả rõ ràng; phân biệt bằng chứng với giả thuyết; báo kết quả kiểm tra lại.

### Bài 4.1: Writing a Clear Bug Report

**Mục tiêu:** Mô tả lỗi bằng hành động, kết quả mong đợi và kết quả thực tế.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| issue | noun | vấn đề được ghi nhận; có thể là lỗi hoặc việc cần trao đổi | report an issue |
| reproduce | verb | tái hiện | reproduce a bug |
| expected result | noun | kết quả mong đợi | describe the expected result |
| actual result | noun | kết quả thực tế | describe the actual result |
| screenshot | noun | ảnh chụp màn hình | attach a screenshot |
| error message | noun | thông báo lỗi | read an error message |
| environment | noun | môi trường chạy hoặc kiểm thử | a test environment |
| version | noun | phiên bản | the app version |

#### Ví dụ Anh–Việt

- **issue:** Please report the issue with a clear title. — Hãy báo vấn đề bằng một tiêu đề rõ ràng.
- **reproduce:** Can you reproduce the bug on your laptop? — Bạn có thể tái hiện lỗi trên máy tính xách tay không?
- **expected result:** The expected result is a saved answer. — Kết quả mong đợi là câu trả lời được lưu.
- **actual result:** The actual result is an empty answer box. — Kết quả thực tế là một ô trả lời trống.
- **screenshot:** Attach a screenshot of the error message. — Đính kèm ảnh chụp thông báo lỗi.
- **error message:** The error message says the file is too large. — Thông báo lỗi cho biết tệp quá lớn.
- **environment:** The bug occurs in the test environment. — Lỗi xuất hiện trong môi trường kiểm thử.
- **version:** Please include the app version in the report. — Hãy ghi phiên bản ứng dụng trong báo cáo.

#### Cách dùng và mẫu câu

Expected result: The app should save the answer. Actual result: The answer disappears. Dùng hiện tại đơn và các bước đánh số để người khác làm lại. Issue rộng hơn bug: không phải mọi issue đều đã được xác nhận là lỗi.

#### Đọc trong ngữ cảnh

**Yêu cầu:** Ghi bước tái hiện và hai kết quả. Đáp án: mở quiz → nhập → Save → refresh; mong đợi còn đáp án, thực tế ô trống.

#### Hội thoại đọc phân vai

Lan: The answer should remain after a refresh.

Nam: What actually happened?

Lan: The answer box was empty.

#### Thực hành

Viết báo cáo gồm Title, Environment, Steps, Expected result, Actual result. Mẫu: Title: Saved answer disappears. Environment: Test version 0.2. Steps: Open quiz, enter answer, click Save, refresh. Expected: The answer remains. Actual: The box is empty. Tự kiểm: bước làm lại đủ rõ và không khẳng định nguyên nhân khi chưa biết.

#### Quiz — 5 câu

1. What is the expected result? (Dựa vào bài đọc.)

   - A. The quiz is deleted
   - B. An empty answer box
   - C. The saved answer remains

   **Đáp án: C.** Lan mong câu trả lời vẫn còn sau refresh.

2. Choose reproduce or deploy: Follow the same steps to ___ the bug.

   **Đáp án: reproduce.** Reproduce nghĩa là tái hiện lỗi.

3. What actually happens after the refresh? (Dựa vào bài đọc.)

   - A. The answer box is empty

### Bài 4.2: Investigating a Problem

**Mục tiêu:** Nói về kiểm tra và dấu hiệu quan sát được mà không nhầm giả thuyết với nguyên nhân đã xác nhận.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| investigate | verb | điều tra; tìm hiểu nguyên nhân | investigate an issue |
| log | noun | bản ghi sự kiện của hệ thống | check the logs |
| connection | noun | kết nối | check the connection |
| timeout | noun | tình trạng hết thời gian chờ | a request timeout |
| cause | noun | nguyên nhân | find the cause |
| evidence | noun, uncountable | bằng chứng; dữ kiện hỗ trợ kết luận | collect evidence |
| hypothesis | noun | giả thuyết cần kiểm tra | test a hypothesis |
| compare | verb | so sánh | compare two results |

#### Ví dụ Anh–Việt

- **investigate:** We need to investigate the missing answer. — Chúng tôi cần tìm hiểu vấn đề mất câu trả lời.
- **log:** We check the logs after the error. — Chúng tôi kiểm tra bản ghi sau lỗi.
- **connection:** Please check the connection to the server. — Hãy kiểm tra kết nối tới máy chủ.
- **timeout:** The request fails with a timeout. — Yêu cầu thất bại do hết thời gian chờ.
- **cause:** We have not found the cause yet. — Chúng tôi vẫn chưa tìm ra nguyên nhân.
- **evidence:** We collect evidence before changing the code. — Chúng tôi thu thập bằng chứng trước khi sửa mã.
- **hypothesis:** Our hypothesis is that the server is slow. — Giả thuyết của chúng tôi là máy chủ phản hồi chậm.
- **compare:** We compare the results on two devices. — Chúng tôi so sánh kết quả trên hai thiết bị.

#### Cách dùng và mẫu câu

Might + động từ diễn tả khả năng: The server might be slow. The log shows ... mô tả bằng chứng. We have not confirmed the cause yet. nói rõ giới hạn hiểu biết. Một timeout không tự chứng minh máy chủ hỏng.

#### Đọc trong ngữ cảnh

**Yêu cầu:** Phân biệt dữ kiện và giả thuyết. Đáp án: log có timeout là dữ kiện; kết nối có thể chậm là giả thuyết.

#### Hội thoại đọc phân vai

Nam: Not yet. The log shows a timeout.

Lan: Could the connection be slow?

Nam: It might be. Let us compare the results on two devices.

#### Thực hành

Viết 3 câu theo mẫu: The log shows a timeout. The connection might be slow. We will compare results on two devices. Tự kiểm: tách quan sát, giả thuyết và hành động kiểm tra; không gọi giả thuyết là kết luận.

#### Quiz — 5 câu

### Bài 4.3: Checking a Fix and Reporting Back

**Mục tiêu:** Báo kết quả kiểm tra lại, phạm vi đã kiểm tra và vấn đề còn tồn tại.

#### Từ vựng

| Từ | Loại từ | Nghĩa | Cụm thường dùng |
|---|---|---|---|
| fix | noun | bản sửa hoặc cách sửa lỗi | verify a fix |
| verify | verb | kiểm chứng | verify the result |
| retest | verb | kiểm thử lại | retest the issue |
| regression | noun | lỗi hoặc sự suy giảm ở hành vi từng hoạt động đúng | check for regressions |
| resolved | adjective | đã được xử lý; đã giải quyết | mark an issue as resolved |
| workaround | noun | cách xử lý tạm để tránh vấn đề, chưa sửa nguyên nhân | use a workaround |
| release | noun | bản phát hành | prepare a release |
| limitation | noun | giới hạn; điều chưa đáp ứng | report a limitation |

#### Ví dụ Anh–Việt

- **fix:** We need to verify the fix. — Chúng tôi cần kiểm chứng bản sửa.

- **regression:** We check for regressions after the change. — Chúng tôi kiểm tra các lỗi ở phần từng chạy đúng sau thay đổi.
- **resolved:** We mark the issue as resolved after verification. — Chúng tôi đánh dấu vấn đề đã giải quyết sau khi kiểm chứng.
- **workaround:** Using another browser is a temporary workaround. — Dùng trình duyệt khác là một cách xử lý tạm.
- **release:** The team prepares a release for the demo. — Nhóm chuẩn bị một bản phát hành cho buổi demo.
